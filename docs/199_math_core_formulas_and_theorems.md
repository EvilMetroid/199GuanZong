### 模块 1：平面几何（18 年 59 题 · 考频 No.1）

#### 1. 核心公式清单
- **相似三角形面积定理**（管综高频核心）：
  若 $\triangle ABC \sim \triangle A'B'C'$，相似比为 $k = \dfrac{AB}{A'B'}$，则：
  $$\frac{S_{\triangle ABC}}{S_{\triangle A'B'C'}} = k^2 = \left(\frac{AB}{A'B'}\right)^2$$
  *规律*：线段比为 $k$，周长比为 $k$，**面积比必为 $k^2$**。
- **扇形弧长与面积公式**（$\alpha$ 为圆心弧度制）：
  - 弧长公式：$L = \alpha r = \dfrac{n\pi r}{180}$
  - 面积公式：$S = \dfrac{1}{2} L r = \dfrac{1}{2}\alpha r^2 = \dfrac{n\pi r^2}{360}$
- **特殊直角三角形边长三边比**：
  - 含 $30^\circ, 60^\circ, 90^\circ$：边长比为 $1 : \sqrt{3} : 2$
  - 含 $45^\circ, 45^\circ, 90^\circ$：边长比为 $1 : 1 : \sqrt{2}$
  - 勾股数必背：$(3, 4, 5)$、$(5, 12, 13)$、$(7, 24, 25)$、$(8, 15, 17)$、$(9, 40, 41)$。
- **等高模型与面积比例定理**：
  两个三角形若高相等，则其面积之比等于对应底边之比：$\dfrac{S_1}{S_2} = \dfrac{b_1}{b_2}$。

#### 2. 考场绝技：阴影面积三大求法
1. **和差法（割补法）**：$S_{\text{阴影}} = S_{\text{规则总}} - S_{\text{空白规则}}$；
2. **等积变形法**：平行线间的同底三角形面积恒等，将不规则阴影平移合并；
3. **容斥原理法**：$S_{A \cup B} = S_A + S_B - S_{A \cap B}$。

### 模块 2：等差与等比数列（18 年 44 题 · 压轴王）

#### 1. 等差数列必背公式与对称性质
- **通项公式**：$a_n = a_1 + (n-1)d = dn + (a_1 - d)$（关于 $n$ 的一次函数）
- **前 $n$ 项和公式**：
  $$S_n = \frac{n(a_1 + a_n)}{2} = na_1 + \frac{n(n-1)}{2}d = \frac{d}{2}n^2 + \left(a_1 - \frac{d}{2}\right)n$$
- **对称性质（秒杀定理）**：
  若 $m + n = p + q$，则：
  $$a_m + a_n = a_p + a_q$$
  *特例*：若 $a_1 + a_n = 2a_{\text{中}}$。
- **奇数项和公式（秒杀神器）**：
  $$S_{2n-1} = (2n-1) \cdot a_n$$
  *口诀*：奇数项等差数列的和等于“项数 $\times$ 正中间的一项”。
- **分段求和性质**：
  $S_n, S_{2n}-S_n, S_{3n}-S_{2n}$ 仍构成等差数列，公差为 $n^2 d$。

#### 2. 等比数列必背公式与对称性质
- **通项公式**：$a_n = a_1 q^{n-1}$
- **前 $n$ 项和公式**：
  $$S_n = \begin{cases} n a_1, & q = 1 \\ \dfrac{a_1(1-q^n)}{1-q} = \dfrac{a_1 - a_n q}{1-q}, & q \neq 1 \end{cases}$$
  > ⚠ **避坑陷阱**：条件充分性判断中涉及等比数列求和时，**必须分类讨论 $q=1$ 与 $q \neq 1$**！遗漏 $q=1$ 是命题人年年设坑的失分点。
- **对称性质**：
  若 $m + n = p + q$，则：
  $$a_m \cdot a_n = a_p \cdot a_q$$
- **分段等比性质**：
  $S_n, S_{2n}-S_n, S_{3n}-S_{2n}$ 仍构成等比数列（当 $S_n \neq 0$ 且 $q \neq -1$），新公比为 $q^n$。

### 模块 3：均值不等式与极值问题（18 年 42 题 · 跨界王）

#### 1. 核心定理与适用条件
对任意非负实数 $a, b \ge 0$：
$$a + b \ge 2\sqrt{ab} \quad \text{或} \quad \frac{a+b}{2} \ge \sqrt{ab}$$
- **取等条件**：当且仅当 $a = b$ 时，等号成立。
- **考场口诀**：**“一正、二定、三相等”**。
  - 一正：各项必须为正数；
  - 二定：求和的最小值时，乘积必须为定值；求积的最大值时，和必须为定值；
  - 三相等：使等号成立的变量取值必须在定义域内能取到。

#### 2. 五大高频变形衍生公式
1. $x + \dfrac{k}{x} \ge 2\sqrt{k} \quad (x > 0, k > 0)$
2. $ax + \dfrac{b}{x} \ge 2\sqrt{ab} \quad (x > 0)$
3. $x^2 + \dfrac{k}{x^2} \ge 2\sqrt{k}$
4. $\dfrac{x^2+a}{x} = x + \dfrac{a}{x} \ge 2\sqrt{a}$（分子分母同除以 $x$ 拆项）
5. 若 $a+b = S$（定值），则乘积 $ab \le \left(\dfrac{a+b}{2}\right)^2 = \dfrac{S^2}{4}$（当 $a=b=\frac{S}{2}$ 时取得最大值）。

### 模块 4：绝对值性质与最值定理（18 年 40 题 · 充要杀手）

#### 1. 核心公式与代数性质
- **非负性**：$|a| \ge 0$；$\sqrt{a^2} = |a|$；$|a|^2 = a^2$。
- **联合非负零和定理**：
  若 $|A| + |B| = 0$ 或 $|A| + B^2 = 0$ 或 $|A| + \sqrt{B} = 0$，则必有：$A = 0$ 且 $B = 0$。
- **绝对值三角不等式（必考高频）**：
  $$||a| - |b|| \le |a \pm b| \le |a| + |b|$$
  - **右端取等条件**：$|a+b| = |a| + |b| \iff ab \ge 0$（同号或至少一个为 0）；
  - **左端取等条件**：$|a-b| = |a| + |b| \iff ab \le 0$（异号或至少一个为 0）。

#### 2. 绝对值几何意义与中位数最值定理
- **几何意义**：$|x - a|$ 表示数轴上动点 $x$ 到定点 $a$ 的距离。
- **函数 $f(x) = |x-a| + |x-b|$ 最值（$a < b$）**：
  - 当 $x$ 落在区间 $[a, b]$ 内时，$f(x)$ 取得最小值，最小值为线段长 $b - a$；
  - 几何解释：在 $a, b$ 之间任何一点到两端点的距离之和都等于两点间距。
- **多绝对值相加中位数定理**：
  求 $f(x) = |x-x_1| + |x-x_2| + \dots + |x-x_n|$（其中 $x_1 < x_2 < \dots < x_n$）的最小值：
  - $n$ 为奇数：$x$ 取**正中间的一个数**（中位数 $x_{\frac{n+1}{2}}$）时，取得唯一最小值；
  - $n$ 为偶数：$x$ 取**正中间两个数闭区间** $[x_{\frac{n}{2}}, x_{\frac{n}{2}+1}]$ 内任意值时，最小值恒定。

### 模块 5：解析几何（18 年 38 题 · 几何化突破）

#### 1. 必背公式清单
- **两点间距离公式**：$d = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}$
- **中点坐标公式**：$x_M = \dfrac{x_1 + x_2}{2}, \quad y_M = \dfrac{y_1 + y_2}{2}$
- **点到直线距离公式（核心中的核心）**：
  点 $(x_0, y_0)$ 到直线 $Ax + By + C = 0$ 的距离：
  $$d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$$
- **两平行线间距离公式**：
  $l_1: Ax+By+C_1=0$ 与 $l_2: Ax+By+C_2=0$ 之间的距离：
  $$d = \frac{|C_1 - C_2|}{\sqrt{A^2 + B^2}}$$
- **直线垂直与平行充要条件**：
  - $l_1 \parallel l_2 \iff \dfrac{A_1}{A_2} = \dfrac{B_1}{B_2} \neq \dfrac{C_1}{C_2}$（或斜率 $k_1 = k_2$ 且截距不同）；
  - $l_1 \perp l_2 \iff A_1 A_2 + B_1 B_2 = 0$（或斜率乘积 $k_1 k_2 = -1$）。
- **圆的标准方程与一般方程**：
  - 标准：$(x-a)^2 + (y-b)^2 = r^2$，圆心 $(a, b)$，半径 $r$；
  - 一般：$x^2 + y^2 + Dx + Ey + F = 0$（要求 $D^2 + E^2 - 4F > 0$），圆心 $\left(-\dfrac{D}{2}, -\dfrac{E}{2}\right)$，半径 $r = \dfrac{\sqrt{D^2+E^2-4F}}{2}$。

#### 2. 直线与圆位置关系的“垂径定理直角三角形”
- **位置判定**：算圆心到直线的距离 $d$ 与半径 $r$ 比较：
  - $d < r \iff$ 相交（有两个交点）；
  - $d = r \iff$ 相切（切线长公式 $L_{\text{切}} = \sqrt{d_{\text{点心}}^2 - r^2}$）；
  - $d > r \iff$ 相离。
- **相交弦长公式（秒杀神技）**：
  $$L_{\text{弦长}} = 2\sqrt{r^2 - d^2}$$
  严禁联立方程组求判别式和韦达定理，直接用勾股定理算弦长！

### 模块 6：概率与数据分析（18 年 44 题 · 稳定得分区）

#### 1. 古典概型与事件概率
- **古典概型**：$P(A) = \dfrac{m}{n} = \dfrac{A \text{ 包含的等可能基本事件数}}{\text{基本事件总数}}$（分子分母必须“同序”或“同无序”）。
- **互斥事件概率加法公式**：若 $A \cap B = \varnothing$，则 $P(A \cup B) = P(A) + P(B)$。
- **相互独立事件乘法公式**：若事件 $A$ 与 $B$ 相互独立，则 $P(AB) = P(A) \cdot P(B)$。
- **对立事件公式**：$P(A) = 1 - P(\bar{A})$（凡遇到“至少有一个”必用对立事件）。

#### 2. $n$ 重伯努利概型（独立重复试验）
- 单次试验事件 $A$ 发生概率为 $p$，在 $n$ 次独立重复试验中，事件 $A$ 恰好发生 $k$ 次的概率：
  $$P_n(k) = C_n^k p^k (1-p)^{n-k} \quad (k = 0, 1, 2, \dots, n)$$

#### 3. 统计特征数（均值与方差）
- **算术平均数**：$\bar{x} = \dfrac{1}{n}\sum_{i=1}^n x_i$
- **方差公式**：
  $$s^2 = \frac{1}{n}\sum_{i=1}^n (x_i - \bar{x})^2 = \frac{1}{n}\sum_{i=1}^n x_i^2 - (\bar{x})^2$$
- **数据线性变换性质（必考填空选型题）**：
  若新数据序列 $y_i = a x_i + b$（每个数据扩大 $a$ 倍加上 $b$）：
  - 新均值：$\bar{y} = a\bar{x} + b$
  - 新方差：$s_y^2 = a^2 s_x^2$（**方差只与倍数 $a$ 的平方有关，加常数 $b$ 不改变方差！**）
  - 新标准差：$s_y = |a| s_x$

### 模块 8：一元二次方程与韦达定理（18 年 18 题）

#### 1. 韦达定理及高频变形公式
方程 $ax^2 + bx + c = 0$ ($a \neq 0$)，判别式 $\Delta = b^2 - 4ac \ge 0$ 时有两根 $x_1, x_2$：
$$x_1 + x_2 = -\frac{b}{a}, \quad x_1 x_2 = \frac{c}{a}$$
- **三大常考变形**：
  1. 平方和：$x_1^2 + x_2^2 = (x_1 + x_2)^2 - 2x_1 x_2 = \dfrac{b^2 - 2ac}{a^2}$
  2. 倒数和：$\dfrac{1}{x_1} + \dfrac{1}{x_2} = \dfrac{x_1 + x_2}{x_1 x_2} = -\dfrac{b}{c}$
  3. 绝对值差（两根距离）：$|x_1 - x_2| = \dfrac{\sqrt{\Delta}}{|a|} = \dfrac{\sqrt{b^2 - 4ac}}{|a|}$

#### 2. 一元二次方程实根分布判定“三步法”
方程 $f(x) = ax^2 + bx + c = 0$ 在区间 $(k_1, k_2)$ 内根的分布，必须联合检验三项：
1. **判别式**：$\Delta \ge 0$（保证有实根）；
2. **对称轴**：$x = -\dfrac{b}{2a}$ 与区间的相对位置；
3. **端点函数值符号**：$f(k_1)$ 和 $f(k_2)$ 的正负号。
